**Architecture:** Keep the frozen 20-case manifest and three runtime modes. Add an append-only per-run result store, immutable config/commit snapshot, sanitized failure taxonomy, token/cost accounting, and a serial read-only canary. **Tech Stack:** Python 3.11+, existing OpenAI-compatible Provider, LangGraph 1.x, Deep Agents 0.x, SQLite checkpoints, pytest, Ruff. No new service dependency.
