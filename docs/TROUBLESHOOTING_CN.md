# 故障排除

[English](TROUBLESHOOTING.md) · [使用指南](USER_GUIDE_CN.md)

| 现象 | 处理与边界 |
|---|---|
| 解压后 EXE 启动失败 | 不单独移动 EXE；保留同目录 `_internal`，完整解压到可写位置。使用项目发布的对应版本，不覆盖旧数据。记录错误及版本；不要通过反复强杀来“修复”。 |
| API offline / 当前项目读取失败 | 先确认启动的是完整桌面包，等待启动或保留日志；浏览器仅前端不具有原生目录/窗口桥。API 图标只是本地 API 连通性，不是模型/MCP/云健康。 |
| 找不到对话 | 检查当前项目、原生/Legacy 入口、分组及归档；`Ctrl+K` 搜索消息和标题。加载失败不代表历史为空，不删除数据库。 |
| 无法切换项目 | 先结束旧版任务、处理草稿与未保存编辑，等待原请求/选择保存/清理。切换确认不取消这些屏障。权限不会继承。 |
| 提交回复未知、按钮锁定 | 保留原输入/key；仅用已有“重试原请求”入口查询/重试，或按界面明确知悉退出。不能把超时当作没有执行，不能另建任务绕过锁定。 |
| 迟到回复、隐藏后有原回执 | 显式显示/采用原回执，不自动重发。隐藏/关闭页面或 HTTP 中止不等于后端排空。 |
| 待审批 / 恢复未完成 | 在对应 run 的执行详情查看审批、拒绝、取消、恢复入口及状态；审批前核对文件/命令/来源。不直接编辑账本、删除 checkpoint 或自动批准旧请求。 |
| 关闭前准备尚未完成 | 等待历史选择、模型设置、子任务、报告、变更或扩展原请求的确认。未知状态按专属知悉提示处理；保留原请求证据。不要强杀或把窗口消失视为所有子进程已结束。 |
| 模型连接失败 | 检查档案、模型、兼容地址与服务支持；不要猜测模型名。测试连接是显式操作，可能收费。错误报告不附 Key、`.env`、DPAPI 文件或完整请求头。 |
| Token/cost 显示未知 | 供应商 usage 缺失和价格声明缺失都可能导致未知；0 不代表免费。声明只用于估算，不是账户硬预算或供应商账单。 |
| Git 快照受限 / worktree 元数据无权限 | 检查真实 workspace；外部元数据经桌面原生选目录/确认，网页不能绕过。快照不承诺 Git clean、过滤器或重命名判定。 |
| 无法逆向 / 验证 | 检查来源 run、preimage 保留、当前文件、静止条件、验证 argv 配置与权限；重新预览和审批。未知操作先处理原回执，不自动重跑。 |
| MCP/Skills 列表为空或旧 | 显式读取配置/缓存，确认选定服务器后探测/读取目录；空缓存不表示服务器没有工具。刷新可能建连/启动本地进程，必须确认。目录不是执行验收。 |
| 小窗口拥挤 | 收起执行详情、模板/权限和说明；帮助菜单可滚动。Legacy 与原生是不同页面，反馈时说明入口和窗口尺寸。不要为布局绕过危险操作提示。 |

## 提交可用反馈

标题栏**帮助 → 问题反馈**打开 [GitHub Issues](https://github.com/zureealLV/Doppel-Agent/issues)。请提供：关于页版本、Windows/WebView2 版本（如已知）、页面入口、最小复现步骤、实际/预期结果、窗口尺寸、脱敏截图/日志。Mock 可复现与真实服务失败分开说明。

不要提交 API Key、认证头、`.env`、DPAPI 内容、真实项目数据库、完整远端目录或私有源码。应用不自动上传日志，也没有内置更新检查、云状态、性能追踪或任务管理器。

保留失败/未知证据；工程测试或界面验收不能替代完整原生生命周期与模型质量评测。
