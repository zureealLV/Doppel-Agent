# Doppel Agent v0.13.2 发布证据与下一阶段

## 补丁原因

`v0.13.1` 已去掉不确定 source map，但 GitHub Windows Runner 仍揭示第二个独立问题：仓库 checkout 的 `frontend_dist/index.html` 使用 CRLF，而 Vite 重建固定输出 LF，严格 committed-bundle 校验因此报告内容相同但字节不同。

## 根治方式

- `.gitattributes` 将 `frontend/**` 和 `src/doppel_agent/web/frontend_dist/**` 固定为 `text eol=lf`。
- 对受管文件执行 `git add --renormalize`，确保 Git blob 与 Vite 输出使用相同字节格式。
- 保留严格的 `git diff --exit-code`，不使用忽略行尾的参数掩盖问题。
- 先从提交后的干净 worktree 执行 `npm ci && npm run build`，确认无差异后才推送 `main`；分支 CI 成功后再创建版本标签。
- Python 3.12 CI 同时暴露完成态与 scheduler 释放之间的 follow-up 竞态；管理器现在等待上一代 future 进入终态后再复用 subagent ID，并增加阻塞 completion sink 的确定性回归测试。
