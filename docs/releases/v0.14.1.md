# Doppel Agent v0.14.1 更新与测试报告

日期：2026-09-30。范围：既有 v0.15 计划的 **Task 3A–3C 安全修补**。
这是 v0.14.x 补丁，不是 v0.15 真实模型矩阵或 v1.0 项目完成声明。

## 原因与更新

9 月 30 日先复核原计划并增加离线对抗审计，复现了五个旧测试未覆盖的
请求级计费/失败分类问题。旧证据保留在
[`v0.15 复测报告`](../../bench/reports/2026-09-30-v0.15-retest.md)，不覆盖成绿色。

本版修复：

1. CLI 和执行器拒绝 NaN、无穷、零、负数、bool 和非数值的价格/预算，
   在快照、结果目录与 runner 启动前验证。每一轮 token usage 要求非 bool、
   非负整数；合法零值保留，后续合法 usage 不能掩盖先前非法值。
2. 评测 Provider 进入不可逆终止状态：缺失/非法 usage 或 transport 失败后，
   当前 runtime 的下一轮和 Deep 内部 Graph fallback 都不能再次发 HTTP。
   这是评测边界修补，不是全项目关闭正常 fallback。
3. 同步 HTTP adapter 为 401/403/429/503、连接失败、超时提供稳定 typed
   failure，不增加重试，不把原始 transport 文本写进评测结果。
4. 失败仍记录 elapsed、fixture hash、独立 `usage_unknown` 和 fallback
   metadata。Decimal 中间计算避免过早浮点溢出；无法表示的 cost 落盘为
   unknown 并停止，aggregate overflow 不产生非法 JSON。
5. live config/result/summary/review schema 升至 **1.1**，拒绝和旧 schema
   混跑；旧文件不可覆盖。审计 artifact 自己的 schema 不变。
6. Python、Vue manifest/lock、API 版本统一为 **0.14.1**；API 从唯一 Python
   version 导入。英文主 README、中文 `README_CN.md` 与旧英文入口兼容。
   CI 的 Windows Python 3.11/3.12 都新增六门禁离线审计。

预算阈值仍是 **run 间止损**，不是 provider 硬消费上限；一次 run 可以超额。
修补不声称中断正在传输的请求，也不保证上游按公开 usage 精确计费。

### 测试中修正的实验配置

- Windows 本机连接拒绝通常约 2 秒；测试把 timeout 从 0.2 s 改为 3 s，
  使 refusal 与 timeout 用例各自测试预定情景，未修改生产超时策略。
- 自定义打包目录第一次命令使用相对 icon/data 路径失败；改为绝对构建
  输入后构建通过。旧 `.dist` 未被覆盖。
- 隔离 wheel 首次只装包、未装 agent extra，CLI 无法导入 LangGraph；
  安装锁定 agent 依赖后复验通过，不把缺依赖当产品缺陷。
- EXE 首次 smoke 误以为新工作区默认 Mock；实际默认 OpenAI-compatible，
  一个**无凭据**请求收到 HTTP 401。随后在仅测试的工作区显式配置 Mock，
  三路径通过。未读取或使用其他项目密钥；这不是付费评测或模型结果。
- 临时 PowerShell helper 创建后访问被拒绝且文件消失，原因未确认；没有
  关闭或修改安全防护。最终用普通 `Start-Process -WindowStyle Hidden`
  启动新包、loopback API 检验和 `CloseMainWindow` 正常收尾。
