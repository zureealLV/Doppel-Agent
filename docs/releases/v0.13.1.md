# Doppel Agent v0.13.1 发布证据与下一阶段

## 补丁原因

`v0.13.0` 的 Python 3.11/3.12、Vitest、TypeScript 与 Vite 构建均通过，但 GitHub Windows Runner 的 committed-bundle 校验发现 `.js.map` 内嵌 `sourcesContent` 会随 checkout 换行变化。可执行 JS/CSS 没有差异，但 source map 不是跨 Windows checkout 的确定产物。

## 修复

- 生产构建关闭 source map，发布 bundle 只保留 `index.html`、哈希 JS 与哈希 CSS。
- 不移动已经推送的 `v0.13.0` 标签，以 `v0.13.1` 补丁版本保留完整审计链。
- 继续执行 Vitest、vue-tsc、Vite build 与 `git diff --exit-code -- src/doppel_agent/web/frontend_dist`。
