# Doppel-Agent 使用指南

[English](USER_GUIDE.md) · [故障排除](TROUBLESHOOTING_CN.md) · [项目首页](../README_CN.md)

## 先了解边界

这是本地编码工作台的**预发布候选**，不是全部 S0–S10 / 原生验收矩阵已完成的稳定版。界面验收、Mock 回归和工程测试不证明真实模型质量、Token 节省或生产稳定性。旧 FAIL/UNKNOWN 保留；付费模型评测仍未进行。

原生工作台的新对话可选 **Graph（LangGraph）、Deep（DeepAgent）或受审 Legacy（Core，原生运行与持久审批）**，创建后不能改引擎。它们使用原生 conversation/run 记录。
**Legacy 历史**页面是旧版对话/执行链；不会导入、转换为原生历史，也不绑定原生上下文面板。独立 Runtime 创建独立原生运行，不接续已有对话。不要把这三个入口当成同一会话。

## 五分钟开始

1. 从预发布页下载 Windows onedir 压缩包，完整解压；`DoppelAgent.exe` 必须与 `_internal` 一起保留。先用可丢弃项目和 Mock 体验，不要直接授权修改重要仓库。
2. 左侧文件夹图标打开项目窗口，选择目录或最近项目，再勾选切换确认并执行。选择目录只登记项目，不自动运行任务。一个窗口只有一个活动项目；切换会等待原请求和 IO 清理，旧版任务须先结束，未发送草稿不会自动保存，权限不继承。
3. 工作台左下角**模型与 API**设置中选择/新建档案。离线用 Mock；真实服务需填写准确的模型名称、兼容地址与 Key。保存不会自动测试连接；**测试连接可能实际调用收费服务**。不要在反馈或截图里提供 Key。已保存 Key 不回显；Windows 保护状态以设置页实际显示为准。
4. 新建对话时选择引擎，在输入框描述任务。建议先只读“理解代码库”或“审查当前项目”。模板仅填提示词，不自动调用模型。选定模型档案和推理力度后，显式发送。
5. 点击右上方**执行详情**查看运行事件、状态、工具与审批；只在检查范围、输入和风险后批准。

## 导航与快捷键

左侧图标依次为工作台、计划与任务、变更与验证、扩展中心、独立 Runtime、Legacy 历史；图标均有悬停名称。标题栏“帮助”提供本文、快捷键、故障排除、GitHub Issues 和实际构建版本，不包含未实现的更新检查或云状态。

| 操作 | 按键/入口 |
|---|---|
| 搜索标题与消息（包括归档） | `Ctrl+K`，兼容 `⌘+K`；Legacy 页搜索旧版，其余页转原生搜索 |
| 对话输入发送 / 换行 | `Enter` / `Shift+Enter`；输入法组字不发送 |
| 搜索选择 / 打开 | `↑↓` / `Enter` |
| 帮助菜单 | 点击或聚焦“帮助”；`↑↓`、`Home`、`End` 导航，`Enter` 激活，`Esc` 关闭，`Tab` 离开 |

最近/归档、分组和对话管理在侧栏及标题区；删除可见历史不是擦除所有审计证据。其他弹窗关闭受各自请求/确认状态限制；`Esc` 不能代替取消、审批或清理。

## 权限与上下文

对话输入栏的 **＋** 展开模板、显式权限和上下文绑定。写入、命令、MCP、委派默认关闭；授权某项不等于自动批准每次危险操作，也不是强 OS 沙箱。独立 Runtime 有同样的明确权限入口。

上下文面板可选择文件片段、创建接受快照、管理事实/约束/决策笔记及其来源，在项目或工作单作用域保存选择。**本次绑定上下文**默认关闭；勾选后先等待选择保存，接收运行时核对来源并冻结输入。不随之后的面板改选而重写历史输入，不授予工具权限。工作单引用前序结果也须符合来源/依赖与选择规则；未保存编辑先保存或放弃。

## 计划、任务与恢复

“计划与任务”可创建/编辑工作单及 revision，设置任务、依赖、执行器、模型和访问权限，保存草稿后明确批准入队；刷新队列查看状态。不会自动批准草稿、重试失败节点或覆盖冲突。历史 revision 是计划定义，不是旧时点运行回放。

重新打开项目时加载已保存的对话、运行及工作单选择；未发送草稿不保证恢复。运行状态、待审批与恢复入口在执行详情中。未知提交锁住表单：只有界面允许时才**重试原请求（相同输入/key）**，不要另建副本或修改 key。迟到回复应采用原回执而非重新调用；关闭或隐藏面板不证明后端已取消/排空。具体状态见[故障排除](TROUBLESHOOTING_CN.md)。

## 变更、审批与验证

“变更与验证”把**当前 Git 快照**与**历史 run 补丁证据**分开。快照不是完整 Git porcelain clean 判定；历史 applied 不证明文件现在还相同，也不证明全部改动由代理生成。从工作台/工作单/独立 Runtime 显式带入原生 run，或输入注册范围内的 run ID。

精确逆向需保留 preimage、重新核对当前文件和来源静止条件，生成预览并重新审批；不是任意 Git 回滚。验证使用项目配置的 argv、明确命令权限及独立审批，不是直接执行任意终端文本。逆向与验证不继承权限、不覆盖彼此的结果，也不代替整版验收。

linked worktree 外部元数据只能经桌面桥**系统选目录＋原生确认精确 workspace/metadata root**授权，只读、owner 作用域、非持久；网页路径/复选框/gitfile 不构成授权。撤销等待已进入读取排空。

## 扩展与报告

扩展中心显式读取配置列表、缓存、MCP 探测/工具目录和 Skills 元数据；进入页不自动连接，不安装扩展、不调用工具、不替运行授权。探测/刷新必须确认；缓存或成功目录不证明实时健康/执行效果。远端文本不可信且可能敏感，不可直接公开。Skills 采用由运行/Policy 决定，不由页面标题决定。

运行报告展示指定原生 run 的事件、usage、声明价格估算与证据范围。默认价格 0 不是免费；未知 usage/cost 不是零，不是已核验账单或账户硬上限。报告、子任务审查可以折叠，但原请求、草稿和未知状态仍保留。分享前人工删去项目路径、代码、服务细节等敏感内容。
